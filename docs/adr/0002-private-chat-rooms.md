# 0002 - Private chat rooms via URL code

## Status

Accepted

## Context

A room per profile (`chat:p01`) would be shared by every visitor of the public demo, so strangers could read each other's messages.

## Decision

The Supabase room is `chat:<roomCode>:<profileId>`. The code comes from the `?room=` URL parameter and is generated by the "Zaproś na drugim urządzeniu" button. Without a code, or without Supabase credentials, the chat uses the scripted bot only. History is stored per `<roomCode>:<profileId>`. The login redirect keeps the original path (`?next=`, internal paths only) so an invited user lands in the room.

## Consequences

- Only people holding the link share a room; the code is not a secret, so this is a demo-grade boundary, not access control.
- The full version replaces rooms with authenticated 1:1 matches stored in the database.
